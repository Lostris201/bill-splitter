SplitEasy — no-account bill splitter

Private, instant, offline-first. Designed to make Splitwise users switch in 10 seconds.

product identity
App nameSplitEasy – Bill & Debt Tracker
SubtitleSplit bills, track who owes you
PlatformiOS first (Expo RN)
CategoryFinance
DifferentiatorZero account, 100% local, instant
EnemySplitwise ("too complicated, forced signup")
"Split bills instantly. No account. No cloud. No one sees your money but you."
core features (MVP only)
  • Add an expense: amount + description + who's involved
  • Even split OR custom amounts per person
  • Persistent debt list: "Alex owes you $18.50"
  • Settle up button — marks a debt paid with one tap
  • History log of settled debts (pro feature)
  • Multiple groups (pro feature — free gets 1)
  • Export summary to share via iMessage / clipboard
what we do NOT build (scope protection)
  • No accounts, no login, no backend
  • No syncing between devices (v1)
  • No recurring expenses
  • No bank/payment integration
  • No graphs or charts
  • No multi-currency (v1)

Screen map

6 screens total. Every tap has one job. Tap a screen to see its spec.

1 — Home (debt list) primary screen ↓

The main screen. Shows all active debts. Two tabs: "They owe you" and "You owe them." Each row: person name, amount, last expense name. Tap row → debt detail. FAB (+) → add expense. If 0 debts: empty state with friendly message and big + button.

DebtListItemTabBar (2 tabs)EmptyStateFAB
2 — Add expense core flow ↓

Sheet modal (bottom sheet). Step 1: amount + description. Step 2: pick people from saved contacts OR type a new name. Step 3: split method — equal / custom. Confirm → saves expense + updates all affected debt totals. No back-end call. Instant.

AmountInputPersonPickerSplitMethodToggleCustomAmountRow
3 — Debt detail settle flow ↓

Per-person breakdown. Shows all expenses contributing to this debt. Total outstanding at top. Settle up button at bottom — tapping shows confirmation sheet "Mark $18.50 from Alex as paid?" → moves to history. Share button generates a plain-text summary.

ExpenseRowSettleButtonShareSummary
4 — History (pro) pro gate ↓

All settled debts, sorted by date. Free users see a blurred list with paywall overlay after the 3rd settled debt. Pro users see full history with person, amount, date. Simple list, no charts.

Free users get 1 default group. Pro unlocks unlimited named groups (e.g. "Apartment," "Trip to Berlin"). Each group has its own debt list and history. Groups screen shows all groups with total outstanding per group.

100% local — AsyncStorage with a simple JSON schema. No Supabase, no Firebase, no auth.

storage key pattern
  • @spliteasy/groups — Group[] serialized JSON
  • @spliteasy/persons — Person[] serialized JSON
  • @spliteasy/expenses — Expense[] serialized JSON
  • @spliteasy/pro_status — { isPro, purchaseType, purchasedAt }
computed debt (never stored)
  • Derive net balance per person on the fly from Expense[] + Split[]
  • Group all unsettled splits by (paidById ↔ personId) pair → net amount
  • Never store a "debt" entity — always computed, always consistent

paywall trigger logic
  • Trigger on: tapping "Groups" when >1 groups exist (free limit)
  • Trigger on: scrolling past 3 items in History tab
  • Trigger on: tapping "Export" button
  • Never trigger mid-expense-add flow — let them complete first
  • Show paywall max once per session (don't hammer)
